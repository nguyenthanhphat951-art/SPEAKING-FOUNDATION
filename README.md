# IELTS Speaking Foundation — Interactive Classroom

A clean, self-contained interactive web application for **IELTS Speaking Foundation (Part 1 & Part 2)**.

## Included Files

- `index.html`: Course Hub & Interactive Classroom Player
- `spkf-lesson1-interactive.html`: Lesson 1 — Express Likes & Dislikes (35 slides)
- `spkf-lesson2-interactive.html`: Lesson 2 — Express Preferences (35 slides)
- `spkf-lesson3-interactive.html`: Lesson 3 — Express Habits & Routines (35 slides)
- `spkf-lesson4-interactive.html`: Lesson 4 — Express Past Experiences (35 slides)
- `spkf-lesson5-interactive.html`: Lesson 5 — Express Changes (35 slides)
- `spkf-lesson67-interactive.html`: Lessons 6–7 — Describe a Person (35 slides)
- `spkf-lesson89-interactive.html`: Lessons 8–9 — Describe a Place (35 slides)
